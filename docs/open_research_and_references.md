# Open Research and Reference List templates

This document provides text templates for AGU/JGR-style Open Research and Reference List entries. Replace placeholder DOI fields after archiving the software release on Zenodo.

## Suggested Open Research statement

```text
The CODE Global Ionosphere Map data used in this study are available from the Center for Orbit Determination in Europe (Center for Orbit Determination in Europe, 2026). The solar-wind and geomagnetic driver data are available from the NASA OMNIWeb OMNI2 database (NASA Goddard Space Flight Center, 2026). The source code for HARP-FiLM is preserved in Zenodo with a permanent DOI (Chen et al., 2026) and is also available for active development on GitHub at https://github.com/research1011/HARP-FiLM.
```
