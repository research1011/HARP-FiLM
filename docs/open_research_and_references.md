# Open Research and Reference List templates

This document provides text templates for AGU/JGR-style Open Research and Reference List entries. Replace placeholder DOI fields after archiving the software release on Zenodo.

## Suggested Open Research statement

```text
The CODE Global Ionosphere Map data used in this study are available from the Center for Orbit Determination in Europe (Center for Orbit Determination in Europe, 2026). The solar-wind and geomagnetic driver data are available from the NASA OMNIWeb OMNI2 database (NASA Goddard Space Flight Center, 2026). The source code for HARP-FiLM is preserved in Zenodo with a permanent DOI (Chen et al., 2026a) and is also available for active development on GitHub at https://github.com/research1011/HARP-FiLM.
```

## Suggested Reference List entries

```text
Center for Orbit Determination in Europe. (2026). CODE Global Ionosphere Maps [Dataset]. Astronomical Institute, University of Bern. http://ftp.aiub.unibe.ch/CODE/

NASA Goddard Space Flight Center. (2026). OMNIWeb: OMNI2 hourly solar wind and geomagnetic data [Dataset]. NASA Space Physics Data Facility. https://omniweb.gsfc.nasa.gov

Chen, J., Yang, C., & Han, L. (2026a). HARP-FiLM: Global ionospheric VTEC forecasting with physics-guided feature modulation and dual-baseline residuals, version 1.0.0 [Software]. Zenodo. https://doi.org/TO_BE_ASSIGNED_BY_ZENODO
```

Use the exact citation format exported by Zenodo after creating the release. The final Reference List entry should include `[Software]` and the Zenodo DOI.
